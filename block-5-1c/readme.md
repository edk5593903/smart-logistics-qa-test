## Ключевые сущности 1С

### Регистры накопления
- **Регистр "Стоимость перевозки"**
  - Измерения: Регион, Весовой интервал
  - Ресурсы: Стоимость за кг
  - Реквизиты: Период

- **Регистр "Остатки грузов на складе"**
  - Измерения: Склад, Номенклатура
  - Ресурсы: Количество, Вес

### Документы
- **Заказ клиента**
  - Реквизиты: Номер, Дата, Клиент, Сумма
  - Табличная часть: Номенклатура, Количество, Цена

- **Отгрузка товара**
  - Движения: Остатки грузов (расход)
  - Связь: Заказ клиента

### Справочники
- **Регионы** (Иерархический)
  - Наименование, Код, Родитель
- **Номенклатура**
  - Наименование, Артикул, Единица измерения, Вес единицы

## Пример задачи из тестового задания

### Задача: Расчёт стоимости перевозки

**Условие:**
Стоимость перевозки зависит от:
- Региона доставки
- Веса груза

Интервалы веса:
- 0-10 кг
- 10-50 кг
- 50+ кг

**Псевдокод запроса к регистру:**

```pseudocode
// Определение интервала веса
Если ВесГруза >= 0 и ВесГруза < 10 То
    ВесовойИнтервал = "0-10кг"
ИначеЕсли ВесГруза >= 10 и ВесГруза < 50 То
    ВесовойИнтервал = "10-50кг"
Иначе
    ВесовойИнтервал = "50+кг"
КонецЕсли

// Запрос к регистру "Стоимость перевозки"
Запрос = НовыйЗапрос()
Запрос.Текст = "
    |ВЫБРАТЬ
    |    РегистрСтоимостьПеревозки.СтоимостьЗаКг КАК СтоимостьЗаКг
    |ИЗ
    |    РегистрНакопления.СтоимостьПеревозки КАК РегистрСтоимостьПеревозки
    |ГДЕ
    |    РегистрСтоимостьПеревозки.Регион = &РегионДоставки
    |    И РегистрСтоимостьПеревозки.ВесовойИнтервал = &ВесовойИнтервал
    |"

Выборка = Запрос.Выполнить()
Если Выборка.Следующий() То
    СтоимостьЗаКг = Выборка.СтоимостьЗаКг
    ИтоговаяСтоимость = ВесГруза * СтоимостьЗаКг
Иначе
    // Обработка ошибки: тариф не найден
    ВызватьИсключение("Тариф не найден для региона " + РегионДоставки + " и веса " + ВесовойИнтервал)
КонецЕсли
```

### Тестовые данные

**Регистр "Стоимость перевозки":**

| Регион | Весовой интервал | Стоимость за кг |
|---------|------------------|------------------|
| Москва | 0-10кг | 50 руб |
| Москва | 10-50кг | 40 руб |
| Москва | 50+кг | 30 руб |
| СПб | 0-10кг | 60 руб |
| СПб | 10-50кг | 50 руб |
| СПб | 50+кг | 35 руб |

**Примеры расчётов:**
- Москва, 5кг: 5 * 50 = 250 руб
- Москва, 25кг: 25 * 40 = 1000 руб
- СПб, 100кг: 100 * 35 = 3500 руб

## Граничные условия и тестовые сценарии

### Позитивные
1. Вес точно на границе интервала (10кг, 50кг)
2. Регион с иерархией (проверка родительского региона)
3. Минимальный вес (0.001кг)

### Негативные
1. Отрицательный вес
2. Несуществующий регион
3. Пустой справочник тарифов
4. Вес = 0 (пустой груз)

## Инструменты тестирования

- **1С:Предприятие** — основная платформа
- **Консоль запросов** — для отладки запросов к регистрам
- **Обработки** — для автоматизации тестов
- **Внешние обработки (.epf)** — для массовых проверок
