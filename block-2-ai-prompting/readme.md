# Блок 2: AI Prompting & Review

## Содержание

1. **prompt.md** — Промпт, отправленный LLM
2. **raw-ai-response.md** — Сырой ответ модели без изменений
3. **review.md** — Экспертный разбор ответа AI
4. **boundary-conditions.md** — Граничные условия и обоснование

## Цель блока

Показать умение работать с AI-инструментами как «вторыми руками», но не слепо копировать вывод модели, а критически оценивать, фильтровать и дополнять.

## Ключевые моменты

- Промпт содержит полный контекст системы (поля, ограничения, API)
- Структура вывода задана явно (категории, формат)
- Ревью фокусируется на специфике логистики и UX
