# smart-logistics-qa-test

> **Тестовое задание QA Engineer — Умная Логистика**  
> ЭТрН · AI Prompting · SQL · API testing · 1С

## О репозитории

Этот репозиторий содержит выполненное тестовое задание для вакансии [QA Engineer в Умная Логистика](https://hh.ru/vacancy/133778281).  
Задание оформлено по инженерным стандартам: каждый блок — отдельная директория с `readme.md`, промпты и AI-ответы — в отдельных `.md`-файлах.

## Структура репозитория

```
.
├── block-1-etrn/          # Блок 1: Тестирование требований (ЭТрН)
│   └── readme.md          # Чек-лист, тест-кейсы, негативные проверки, баг-репорты
├── block-2-ai-prompting/  # Блок 2: AI Prompting & Review
│   ├── readme.md          # Описание хода решения
│   ├── prompt.md          # Промпт, отправленный LLM
│   ├── raw-ai-response.md # Сырой ответ модели без изменений
│   ├── review.md          # Экспертный разбор ответа: ошибки, упущения, лишнее
│   └── boundary-conditions.md # Граничные условия и обоснование
├── block-3-sql/           # Блок 3: Анализ данных (SQL / PostgreSQL)
│   └── readme.md          # SQL-запросы с объяснением логики
├── block-4-api/           # Блок 4: Тестирование API (/api/v2/orders)
│   └── readme.md          # Чек-лист с HTTP-кодами и сценариями
└── README.md              # Этот файл
```

- **ЭТрН** — электронная транспортная накладная, обязательная с 01.09.2026 (ФЗ №259)
