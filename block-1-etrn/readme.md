## Ключевые аспекты ЭТрН

### Основные поля документа
- Номер накладной (уникальный идентификатор)
- Дата и время отправки
- Отправитель (ИНН, наименование, адрес)
- Получатель (ИНН, наименование, адрес)
- Перевозчик (ИНН, транспортное средство, водитель)
- Груз (наименование, вес, объём, количество мест)
- Маршрут (пункты погрузки/разгрузки)
- Стоимость перевозки

### Валидация и граничные условия
- Обязательность полей (ИНН, даты, груз)
- Форматы данных (ИНН 10/12 цифр, даты ISO 8601)
- Диапазоны значений (вес > 0, объём > 0)
- Логические зависимости (дата доставки >= дата отправки)
- Соответствие справочникам (коды ОКАТО, ОКВЭД)

### Интеграция с внешними системами
- ФГИС ЕАЭС (Евразийский экономический союз)
- ФНС (налоговая служба)
- Системы электронной подписи (ЭЦП)
- Транспортные информационные системы

## Тестовые сценарии (краткий обзор)

1. **Позитивные сценарии**
   - Создание ЭТрН с валидными данными
   - Отправка груза по маршруту
   - Получение подтверждения доставки

2. **Негативные сценарии**
   - Невалидный ИНН отправителя/получателя
   - Некорректный формат даты
   - Отрицательный вес/объём груза
   - Дата доставки раньше даты отправки

3. **Граничные условия**
   - Минимальные/максимальные значения полей
   - Пустые обязательные поля
   - Специальные символы в текстовых полях
   - Дубликаты номеров накладных

## Инструменты тестирования

- **Postman** — для проверки API создания/валидации ЭТрН
- **SoapUI** — для SOAP-интеграций с ФГИС
- **xmllint / XSD validators** — для валидации XML-структуры
- **BPMN редакторы** — для моделирования процессов (Camunda Modeler)
- **Jira** — для документирования баг-репортов
