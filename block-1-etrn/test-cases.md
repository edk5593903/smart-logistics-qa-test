# Тест-кейсы: Электронная транспортная накладная (ЭТрН)

## Позитивные тест-кейсы

### TC-001: Создание ЭТрН с валидными данными
**Приоритет:** Высокий  
**Предусловия:** Пользователь авторизован в системе

**Шаги:**
1. Открыть форму создания ЭТрН
2. Заполнить поля:
   - Отправитель: ИНН 7707083893, ООО "Логистика+"
# Чек-лист тестирования ЭТрН

## Позитивные сценарии

| # | Тест-кейс | Приоритет |
|---|-----------|-------------|
| 1 | Создание ЭТрН с валидными данными | High |
| 2 | Отправка ЭТрН в ФГИС | High |
| 3 | Получение подтверждения от ФГИС | High |
| 4 | Редактирование ЭТрН (статус "Черновик") | Medium |
| 5 | Изменение статуса на "В пути" | Medium |

## Негативные сценарии

| # | Тест-кейс | Приоритет |
|---|-----------|-------------|
| 1 | Невалидный ИНН отправителя (9 цифр) | High |
| 2 | Отрицательный вес груза (-5 кг) | High |
| 3 | Дата доставки раньше даты отправки | High |
| 4 | Пустое обязательное поле (адрес получателя) | High |
| 5 | Некорректный формат даты (dd.mm.yyyy вместо ISO) | Medium |

## Граничные условия

| Поле | Boundary Values | Ожидаемое поведение |
|------|----------------|------------------|
| Вес | 0, 0.001, 0.01, 9999 | 0 = error, rest = valid |
| ИНН | 9 цифр, 10, 12, 13 | 10/12 = valid, rest = error |
| Дата | сегодня, завтра, вчера | сегодня/завтра = valid |
